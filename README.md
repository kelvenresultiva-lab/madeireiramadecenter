# Essência Madeiras — site completo

Esta é a versão atual do template, com cabeçalho reduzido, rodapé completo, imagens e todas as seções. O código é HTML, CSS e JavaScript puro, sem etapa de compilação.

## Como abrir

1. Extraia este ZIP em uma pasta.
2. Abra essa pasta no Claude Code.
3. Com Node.js instalado, execute `npm run dev`.
4. Acesse http://localhost:3000.

Também é possível abrir `index.html` diretamente no navegador. As fontes do Google precisam de conexão com a internet.

## Arquivos

- `index.html`: página completa, CSS dentro de `<style>` e JavaScript no final.
- `assets/`: imagens incluídas, com caminhos relativos.
- `CLAUDE.md`: contexto e orientações para continuar o trabalho.
- `server.mjs`: servidor local simples, sem dependências.
- `IMAGENS.md`: origem e contexto das imagens.
